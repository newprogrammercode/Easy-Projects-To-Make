# ⏱️ Timer Project

A clean command-line digital timer application built to practice Python fundamentals, timing logic, and state handling.

---

## 💻 Technologies Used
* **Python 3.x**
* Built-in `time` and `tkinter` modules
* Downloaded `pygame` package 

---

## 📋 How to Run Locally

1. Make sure you have Python installed on your computer.
2. Open your terminal or command prompt inside this folder.
3. Run the application using:
   ```bash
   python main.py
   ```
